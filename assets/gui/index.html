    How Listening works

    1. Pick a repo. Picking only opens its record. Nothing starts.
    2. Press Listen. One click grants capture for that repo alone.
    3. Rocky checks every 10 seconds. He reads the text files Git tracks, only while rocky dash stays open. No daemon.
    4. Each change lands here as a redacted snapshot, with how Rocky knows it.

    How Rocky knows

    • Heard on disk The file changed on disk. Proves the change, not who made it.
    • Matches commit Snapshot text equals a Git commit exactly.
    • Reported by tool An agent hook reported the event itself.
    • Near in time, possible link Close in time or content. Context only, never cause.
    • Snapshot only Rocky holds the event with no link yet. Unknown is not nothing.

      • Stop listening ends capture. History stays.
